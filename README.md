# Adaptation: The World Remembers (adaptation)

Мод для Minecraft **26.1.2** на **Fabric**. Мир изучает твои привычки и отвечает на каждую из них.

## Механики
1. **Привычка** — еда, которую ты ешь 5+ раз подряд, «преснеет»: нарастает голод. Сон на одной
   постели 3+ ночи подряд — «оседлость» и шанс кошмарной засады при пробуждении.
2. **Враги учатся** — убивай мобов одним стилем оружия в одной зоне, и новые мобы там получат
   броню, скорость и шанс полностью отразить твой удар. Смени оружие — зона «забудет» (уроки
   тают за 10 минут). Стили: SWORD, AXE, RANGED (лук/арбалет/трезубец), MACE, TOOL, OTHER.
3. **Осада гнезда** — при оседлости 3+ ночей ночью у базы появляется **Разведчик**
   (беззвучный зависший фантом). Убей его за 5 минут — набег откладывается на 2 дня;
   прозеваешь — начнётся набег, сила которого растёт с оседлостью (до ведьм и криперов).
4. **Фазы Ярости** — каждые 4–8 игровых дней мир входит в фазу на 2–4 игровых часа:
   ГОЛОД, МГЛА или МИМИКРИЯ (мимикрия: сундуки-подражатели, 22% при открытии — засада).
   Предвестник фазы — короткий накат мглы. Привычка к одной еде усиливает фазу ГОЛОД.
5. **Алтарь Забвения** — крадучись используй жемчуг Края на магнитном камне: сбрасывает твои
   привычки, зоны обучения врагов и откладывает фазы. Перезарядка — 4 игровых дня.

## Команды
- `/adaptation` — показать твои привычки, оседлость, зоны обучения и статус алтаря.
- `/adaptation reset` — полный сброс состояния (нужны права оператора).

## Сборка (IntelliJ IDEA Community 2025.3+)
1. Установи JDK 25 (Temurin/Oracle — подойдёт тот же, что для самой игры).
2. Распакуй архив проекта в любую папку.
3. `File → Open` — выбери папку проекта, доверься проекту (Trust Project).
4. Если IDEA спросит про Gradle-обёртку (wrapper отсутствует — это нормально):
   выбери **Use local distribution** / bundled Gradle. Требуется Gradle **9.4+**
   (Loom 1.19 не работает со старыми версиями).
5. Дождись синхронизации (скачает зависимости, несколько минут).
6. Собери мод: панель Gradle (справа) → adaptation → Tasks → build → **build**.
   Либо в терминале: `gradle build` (если Gradle установлен в PATH).
7. Готовый jar: `build/libs/adaptation-1.0.0.jar`.

## Установка
- Fabric Loader **0.19.4+** для 26.1.2 (https://fabricmc.net/use/)
- Fabric API **0.154.2+26.1.2** в папку `mods`
- `adaptation-1.0.0.jar` в ту же папку `mods`

## Первая проверка в игре
1. Создай тестовый мир, `/time set night`.
2. `/gamemode survival`.
3. Съешь одну и ту же еду 5+ раз подряд (например, запечённый картофель) — на 5-м разе
   придёт сообщение «Мир адаптировался» и появится голод.
4. Поспи на одной постели 3 ночи (`/time set night` → сон → `/time set day`) — на 3-й+ ночь
   у базы появится Разведчик.
5. `/adaptation` — смотри счётчики.
6. Алтарь: поставь магнитный камень, возьми жемчуг Края, зажми Shift и кликни ПКМ по камню.
